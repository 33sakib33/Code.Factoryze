# Security policy

Factoryze 0.1 and 0.2 are unreleased previews. There is no supported stable release yet. Security fixes are reviewed against the current `main` branch and any affected preview builds.

Please do not disclose a vulnerability, exploit or credential in a public issue. If GitHub's **Report a vulnerability** option is available under this repository's Security tab, use it to send the report privately to the maintainers. If it is not available, open a public issue containing only a request for a private security contact; do not include exploit details. Maintainers should enable [GitHub private vulnerability reporting](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository) before making the repository public.

Include the affected version/commit, platform, impact and reproduction steps in the private report. Do not test against other users' accounts, classrooms or paid provider resources without authorization.
